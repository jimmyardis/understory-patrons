# Understory Patrons

Working patron prospectus for **Understory — A Natural History of South Carolina**.

## Publish with GitHub Pages

1. Open **Settings → Pages**
2. Under **Build and deployment**, choose **Deploy from a branch**
3. Select **main**
4. Select **/(root)**
5. Save

The site is intentionally static: no build process, npm, or framework is required.

## Current purpose

This is the Vince review/demo version. It contains the opening historical and patronage sequence. The final public edition will add the complete modern Understory half, locally hosted archival images, and final provenance/source treatments.
